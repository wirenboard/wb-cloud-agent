# Wiren Board Agent

[![Coverage Status](https://coveralls.io/repos/github/wirenboard/wb-cloud-agent/badge.svg)](https://coveralls.io/github/wirenboard/wb-cloud-agent)

Агент с использованием аппаратной подписи для получения обновлений с wirenboard.cloud.
[Подробная документация](https://wirenboard.com/wiki/Wiren_Board_Cloud)

## Как установить

Обновите список пакетов на контроллере и установите пакет

```
apt update && apt install wb-cloud-agent
```

## Как использовать

Для подключения контроллера через веб-интерфейс воспользутейсь [разделом настроек](https://wirenboard.com/wiki/Wiren_Board_Cloud#%D0%94%D0%BE%D0%B1%D0%B0%D0%B2%D0%BB%D0%B5%D0%BD%D0%B8%D0%B5_%D0%BA%D0%BE%D0%BD%D1%82%D1%80%D0%BE%D0%BB%D0%BB%D0%B5%D1%80%D0%B0_%D0%B2_%D0%BE%D0%B1%D0%BB%D0%B0%D0%BA%D0%BE).
Чтобы получить ссылку для подключения контроллера в консоли, выполните:
```
wb-cloud-agent
```

## Восстановление повреждённых конфигов

Агент не останавливается из-за испорченного файла: если конфиг провайдера
`/etc/wb-cloud-agent/providers/<провайдер>/wb-cloud-agent.conf` отсутствует, пуст или не читается как JSON,
он восстанавливается автоматически из поставляемых настроек с адресом production cloud
`https://wirenboard.cloud`. Если поставляемый конфиг повреждён, используются встроенные значения агента.
Непустой испорченный файл перед перезаписью
сохраняется рядом как `wb-cloud-agent.conf.broken-<дата>`, каждое восстановление пишется в журнал с уровнем
WARNING (`journalctl -u wb-cloud-agent@<провайдер>`). Восстановление применяется и для провайдеров,
добавленных с `--name`: имя каталога не используется как адрес облака.

Если повреждённый файл или восстановленный конфиг невозможно сохранить из-за прав, read-only `/etc`,
ошибки файловой системы или другой ошибки ввода-вывода, агент завершает запуск с кодом 6 и пишет ошибку.
Исходный файл при этом не перезаписывается, а systemd не запускает бесконечный цикл рестартов. Команды
управления провайдерами не выполняют облачные действия, если адрес провайдера неизвестен из-за повреждённого
конфига; сначала нужно восстановить исходный файл или исправить права.
